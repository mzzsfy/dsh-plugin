# dsh-think-expand 兼容性测试

包定位:纯前端插件,默认流式思考自动展开最新一条思考行(思考正文可见性控制),可选「展开全部消息」模式(设置卡片开关,持久 localStorage)——追加独立的工具行展开机(planTools),思考机行为不变,两机独立 registry 互不接管。Host 半区 src/index.js 为零依赖空壳(`export function apply() {}`,profile 行仅用于让 client 模块系统发现本包 dsh.client 声明并服务浏览器半区 src/client.js)。行为全集:流式思考行出现(data-state="running")自动展开最新一条;新思考行出现收起上一条由插件展开的行;用户手动展开/收起优先,识别后不再干预;打开会话/刷新/切换会话展开最后一条、其余保持收起;插件动作前置底时高度落定后回补置底;同一时刻每机至多一条行展开(思考一条+工具一条并存)。工具展开机:行根为 flowItem 全集减思考行,可展开性按官方 data-expandable 标记(preparing 行天然落选),目标行=文档序最后一个可展开行,手动收起=已读、手动展开=manual,首扫中性(仅插件展开过行后识别手动);开关实时生效,切回仅思考时收起插件展开的工具行、手动行保留。宿主依赖为官方 DOM 字面量、client 模块系统注册形态与 slots 服务(设置卡片声明门控,服务未就绪时 client 半区整体挂起即干净禁用);任一依赖点缺失表现为对应功能不干预(干净降级),不加载崩溃、不阻塞 boot。

### L2 装载层

- 冒烟覆盖:scripts/smoke-load.mjs 遍历 packages/ 下全部含 package.json 的目录(symlink/junction 一并收),逐个动态 import 各包 main——OK/FAIL 逐行输出,入口缺失打 SKIP,任一包加载失败即 exitCode 1;`--profile` 参数切换为遍历 profile node_modules/@mzzsfy 测安装副本。本包 main 为 src/index.js,在清单内:空壳零 import,冒烟仅验证入口模块可解析可加载;src/client.js 非 main 不被该脚本 import,其装载由本层 boot 判据与 L3 覆盖。本包无宿主服务依赖与 peerDependencies,不存在缺依赖 pending 面。
- 隔离环境 boot 判据:`dsh plugin add @mzzsfy/dsh-think-expand` 经 cordis.patch.yml 在 profile root 插入行(id=think-expand,name=@mzzsfy/dsh-think-expand),重启一次宿主完成首装载;判据 = activation live + diagnostics findings 0 + 无 pending/装载错误 + 页面无 `Failed to load plugins`。host 半区空壳不注册任何服务,任何宿主代际下不 pending、不拖死 boot;client 半区经 `__ModuleLoader__.load` 自注册,装载失败仅表现为功能不生效(世代槽缺失,L3 #2 直接暴露),不产生页面级报错。

## L3 功能面断言

断言于隔离宿主上以 playwright 执行;选择器与官方字面量均对照 src/client.js 校准。沿用既有等待约定:页面加载/会话打开/刷新等 9s、交互后等 2s、渲染断言前等 2.5s;流式组受模型响应延迟支配,不用固定等待,按 2s 间隔轮询、单步上限 30s。环境前提见专项注意首条。

宿主 DOM 依赖点(断言与排障共同参照;全部为官方字面量,缺失后果即本包的干净降级形态):

| 依赖点 | 形态 | 缺失后果 |
|---|---|---|
| `[data-conversation-scroll]` | 官方滚动容器字面量属性 | 容器缺失插件待命,无任何动作 |
| `[data-variant="think"]` | 官方思考行根节点字面量属性 | 行集为空,不干预 |
| `[data-disclosure-row]` | 官方折叠头字面量属性 | 行 headable=false,该行永不干预 |
| `data-state` ∈ running/ok | 官方行状态字面量(仅思考模式;全部消息模式不限字面量) | 非两值即该行识别失败,不干预(全部消息模式下该行退出行集) |
| `aria-expanded` | 官方展开态字段,点击动作的唯一判定依据 | 展开判定失效,动作不触发 |
| `[class*="thinkBody"]` / `[class*="bodyWrap"]` | 正文容器哈希段子串匹配(思考 = thinkBody,工具 = bodyWrap;折叠头摘要 `_content_` 不是正文,不读取) | bodyText 空:仍展开但不登记,接管收起退化 |
| `hidden` 祖先 + `beforematch` | 官方回合完成后自动隐藏过程组(可搜索隐藏);插件对仍负责的末行派发官方揭示事件恢复可见 | 过程组保持官方隐藏形态,恢复失效表现为完成态不重开,流式行为不受影响 |
| `[data-turn-process]` | 官方回合过程汇总折叠按钮;最新回合折叠时过程组内容(工具行整批)不在 DOM | 折叠判据失效,工具行整批缺席时不展开,表现为最新回合工具行不自动展开 |
| `__ModuleLoader__.load` | 宿主 client 模块系统注册形态(id=完整包名) | client 半区不装载,世代槽缺失 |

本包会话区不注入样式、不写任何 DOM 属性,唯一 DOM 写操作是对折叠头调用 `click()`;设置卡片样式注入 head 且带 `data-plugin` 标记(见 L4)。

模型 API 搭建(免真实配额,2026-09-24 起):宿主 providers 指向仓库公共 LLM 模拟器即可让本组可测——`node scripts/echo-upstream/cli.mjs` 起服(默认 18123,详见 `scripts/echo-upstream/兼容性测试.md`),经 gateway 设置 RPC 注册 provider(baseURL `http://127.0.0.1:18123`,api 按协议 anthropic-messages 或 openai-completions,models 含 `echo-model` 与 `echo-model-think` 两条),会话选中 `echo-model-think` 发话即产生真实思考流(模拟器 -think 场景回 thinking/reasoning 内容),宿主思考行按流式渲染,UI 断言不受影响;`-slow` 变体(模型条目用 `echo-model-think-slow` 需模拟器场景支持组合时另起 `--tokens` 无关,直接以 `-slow` 后缀模型发话)可拉长流式窗口便于人工观察。不再依赖真实 API 配额,「环境不可测」仅适用于未搭模拟器且无真实 API 的环境。

## 专项注意

- 环境前提:隔离 profile 预置会话样本必须含思考内容(思考正文才存在)。样本 A(单轮单思考行,如「回复一个字:壹」)必配,#4–#6 依赖其单行形态;样本 B(同一会话多轮多思考行)用于 #7–#10 的「仅最后一条」断言。流式组(#11–#19)要求宿主配置可用模型 API,且发送回合处于产生思考的形态(会话思考开关开启/模型支持思考,与样本 A 的产生条件一致),API 不可用或回合不产思考时整组记「环境不可测」并在报告注明,不判失败但不得冒充通过。
- 样本初始状态:打开样本前各思考行须处于官方默认收起态(planFinal 才有展开动作可观察);上一轮测试遗留的展开态刷新页面即重置(刷新后官方默认全收起,插件重展开最后一条)。
- 误判防范:
  - offsetHeight 语义:`offsetHeight > 0` 即展开、折叠态为 0,不受 CSS 可见性类属性干扰;该判据前提是官方以高度/显隐方式折叠,若官方改用 visibility/opacity 类折叠则判据失效——先核官方 DOM 实测再判本包
  - 正文选择器命中全部行:`[class*="thinkBody"]` / `[class*="bodyWrap"]` 按文档序返回所有正文容器,展开的通常是最后一条;断言展开体必须锚定行内查询(row.querySelector),勿以 b[0] 代表展开体(样本 A 单行除外,#6 已注明语境)
  - 类名漂移:#6/#7 length=0 时先核官方类名是否改名(thinkBody/bodyWrap 为 CSS Modules 哈希段子串匹配),再查本包 pending;类名漂移时插件仍展开(bodyText 空仅展开不登记),表现为接管收起退化而非展开失效
  - 完成态判定:回合完成后官方把过程组设为 `hidden="until-found"` 并重置子折叠,属官方自动收起而非用户已读;断言「流式结束保留展开」(#13/#14)必须在隐藏生效前采样,完成态以「末思考正文可见(过程组未被 hidden 或已被插件恢复)」为准
  - 状态字面量扩张:识别仅认 data-state running/ok,宿主引入新字面量时行识别失败、插件整体不干预(干净降级),表现为「不自动展开」——先核官方行状态字面量再判本包回归
  - 手动操作污染标记:手动展开/收起会写入 manual/read 标记(页面生命周期内有效),断言失败重试前先刷新页面重置 registry,勿带脏标记重试
  - 流式时序:新思考行出现与展开动作间隔为 50ms 防抖,2s 轮询不会错过展开态;模型延迟波动大,单步上限 30s 未出现按超时计,先查宿主日志确认请求是否发出;流式中手动展开较旧行属时序敏感场景,L3 不设断言(手动意图的确定性形态见 #15 与 #16)
- 危险操作:本包无宿主服务写入,唯一持久化是开关 localStorage 键(不入宿主数据目录);模拟点击折叠头无破坏性,测试不留脏数据。流式组断言曾真实消耗模型 API 配额,现可经公共 LLM 模拟器(`scripts/echo-upstream/兼容性测试.md`)零配额执行;使用真实 API 时重试勿频繁发送长消息。
- 断言保留记录:原 2 项全部保留融入,无一删除——原 1 → 新 1(措辞原样保留);原 2 → 新 6(限定样本 A 单思考行语境,b[0] 即展开体,预期不变)。多行场景的展开可见性改由 #7 以行内锚定方式覆盖。

## 维度检查点(补充)

1. **双机独立**:思考机与工具机互不接管;思考展开时工具行不受影响,反之亦然。
2. **流式边界**:仅最新一条 running 行展开;新行出现时收起上一条由插件展开的行;用户手动展开的行不被强制收起。
3. **置底回补**:用户停留在底部时随流滚动;用户上滚后不抢滚动;流结束不重复展开。
4. **开关往返**:关闭「展开全部」只影响工具机;刷新与重启后保持;卸载恢复默认。
5. **结构变化**:宿主行标记/层级变化时停止展开并保留手动能力,不产生 console 错误。
