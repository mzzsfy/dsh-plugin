# dsh-session-manager 兼容性测试

包定位:会话自动归档与管理(超期自动归档、归档面板、删除进回收站或插件回收区、已删除台账与一键重挂载)。宿主半区八条 `/api/session-manager/*` 路由 + settings namespace `session-manager`(autoArchiveDays / autoArchiveIntervalHours 两项,0 = 关闭);归档评估三触发源共用同一门闩(新会话创建、settings 就绪启动补扫、周期轮,周期轮经宿主 timer 软依赖,缺失仅周期轮停用并在面板提示降级)。client 半区唯一 UI 注入面为 `settings.section` 插槽(分区 id `session-manager`、order 46、label「会话归档」)+ 设置导航图标声明 + 带 `data-plugin` 的文档级样式注入;归档/删除操作反馈与归档集合差分通知经公共依赖 `@mzzsfy/dsh-toast`(hard require,由本包 dependencies 随装、cordis.patch.yml 代挂宿主占位条目)。历史输入浮层、插话撤回与对话 fork 已迁至 dsh-context-manager,工作区文件夹运行标记已迁至 dsh-turn-notify:本包 src 已无 conversation.input.dock 注入、无会话树 DOM 扫描代码(client.js 仅残留一条迁移注释,无对应实现),与这两包无 UI 插槽竞争。

### L2 装载层

- smoke-load 覆盖:scripts/smoke-load.mjs 自动枚举 packages/ 全部含 package.json 的目录,逐个 dynamic import 其 main,无手工清单。本包 main 为 src/index.js,在遍历范围内:静态 import 的宿主 peer(@deepseek-ai/dsh-storage-domain、@deepseek-ai/schemastery、zod)解析失败或其被引用导出缺失(链接期错误)当场 FAIL;本包命名导出契约由宿主装载判据与 L1 用例覆盖(name 无专项检出,宿主激活失败兜底)。src/client.js 为浏览器单文件自包含格式,不经该脚本加载,其装载性由本层 boot 判据与 L1 client-scope / client-id 补齐;src/core.mjs 与 src/trash.mjs 为 index.js 静态依赖,随 main import 一并覆盖。支持 `--profile` 测 profile 安装副本。
- 隔离环境 boot 判据:activation live + diagnostics findings 0 + boot 日志无本包 pending / 装载错误。
- 干净禁用形态(缺依赖必查):host 半区七项 inject(webServer / workspaceRegistry / sessionQuery / storageDomain / agents / sessions / sessionPersistence)任一不可满足时整体未激活,不拖树、不阻塞 web 启动;timer 为软依赖(ctx.inject(['timer']) 顶层注册,不嵌套 settings 回调),宿主定时服务缺失或调用失败时插件照常激活,仅周期轮停用,`GET /api/session-manager/status` 返回 `periodic.running=false` 携原因文案,面板顶部显示降级提示,session/created 触发与启动补扫不受影响。

## 专项注意

- 迁移事实对测试的影响:本包 client 已无会话树渲染与输入浮层注入——工作区文件夹运行标记迁至 dsh-turn-notify,历史输入浮层 / 插话撤回 / 对话 fork 迁至 dsh-context-manager;client.js 末段残留一条运行标记实现注释,其后无任何对应代码,勿据该注释推断本包有树注入面。原断言 #2(treeitem > 0)保留但改义:它验证的是宿主自身会话树渲染健康,不再代表本包功能;旧文档「与 context-manager 同插槽共存场景(浮层 z-index)」随浮层迁出作废,浮层相关断言一律归对端包文档。
- 端口:隔离宿主端口按当轮环境选择(专项 3083 / 整体 9191),禁止指向生产 3080。
- 破坏性边界:删除链确认路径真实回收会话产物(系统回收站或插件回收区),默认回归只走 #15 取消路径(零请求);真实删除仅对可弃夹具会话执行,执行后在「已删除」区核对处置模式文案与台账条目,并以「移除记录」收尾(幂等,可安全点);「重新挂载」对未还原的系统回收站条目直接拒绝(无副作用),可放心做负路径。
- 深测界定:「深测」指超出本回归文档的专项逐项测试,项目与结果记录于专项计划;表内标注「留待专项深测」的项回归不执行、不算失败。
- 配置污染防范:#7 合法值提交会真实写入宿主 settings,测试完把阈值与周期恢复默认(7 与 24);0 = 关闭是合法值,勿以「归档没发生」倒推配置失效。非法输入前端拦截不发请求(网络面板无 POST)是设计行为,不是功能缺失。
- 误判防范:
  - 面板数据 = 会话行 ∩ 归档集合,归档集合为空时面板恒为空态——空态是数据面结论,勿判为装载失败;装载失败以 #1 / #3 / #5 为准。
  - 已删除列表加载失败时面板保留旧数据并 console.warn,不渲染成「无记录」;看到旧数据残留先查控制台再下结论。
  - 周期降级提示仅在 status.periodic.running=false 出现;timer 正常环境出现该提示即查宿主定时服务,而不是改断言。
  - 控制台偶发的其他插件报错为环境噪音,断言只锚定本包标志(style data-plugin 计数、`.sm-*` 类名、`/api/session-manager/*` 探针响应)。
  - L1 路由层用例在未安装 peer 依赖的仓库环境整批 skip(2 个纯逻辑用例除外);skip 不是通过,宿主升级回归前先装依赖重跑。
- 与 context-manager 同测边界:Alt+↑ 浮层、插话撤回、fork 断言全部归对端文档;本包只断言「会话归档」分区自身与两分区同页并存互不影响;对端 fork 产生的新会话不影响本包归档集合,本包删除与取消归档不触碰对端任何路由。归档通知(单条 / 多条 / 截断文案)依赖真实归档事件差分,隔离环境无天然触发源,逻辑由 L1 core / parity / client-toast 锁定;页面级验证无夹具时不执行、不算失败,留待专项深测。
