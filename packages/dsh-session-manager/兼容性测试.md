# dsh-session-manager 兼容性测试

包定位:会话自动归档与管理(超期自动归档、归档面板、删除进回收站或插件回收区、已删除台账与一键重挂载)。宿主半区九条 `/api/session-manager/*` 路由 + settings namespace `session-manager`(autoArchiveDays / autoArchiveIntervalHours 两项,0 = 关闭);归档评估三触发源共用同一门闩(新会话创建、settings 就绪启动补扫、周期轮,周期轮经宿主 timer 软依赖,缺失仅周期轮停用并在面板提示降级)。client 半区唯一 UI 注入面为 `settings.section` 插槽(分区 id `session-manager`、order 46、label「会话归档」,含自动归档阈值/周期)+ 设置导航图标声明 + 带 `data-plugin` 的文档级样式注入;归档/删除操作反馈与归档集合差分通知经公共依赖 `@mzzsfy/dsh-common-tools`(hard require,由本包 dependencies 声明随装、cordis.patch.yml 自带本包装载行`session-manager-dsh-common-tools`;宿主按包名把各消费插件的装载行合并成单份 client 模块)。历史输入浮层、插话撤回与对话 fork 已迁至 dsh-context-manager,工作区文件夹运行标记已迁至 dsh-turn-notify,会话列表瘦身已迁至 dsh-bug-perf:本包 src 已无 conversation.input.dock 注入、无会话树 DOM 扫描代码、无 `sessionController.list` 包装(client.js 仅残留一条迁移注释,无对应实现),与这几个包无 UI 插槽竞争。归档行标题下展示更新时间与日志文件大小,大小经 `POST /api/session-manager/sizes` 批量查询(client 按 500 条分批,host 逐会话读公共 `stat` 快照的 `sizeBytes`、缺失时退回文件 stat,并发 8,单条失败隔离),主列表/工作区分组/搜索平铺共用同一行组件。

## 测试分层与执行流程

| 层 | 内容 | 手段 |
|----|------|------|
| L1 单元层 | test/ 下 13 个 `*.test.mjs`,覆盖纯逻辑层 / 路由层 / 处置执行器 / 镜像与源码契约(清单见下) | 包目录 `node --test "test/*.test.mjs"` |
| L2 装载层 | smoke-load host 半区加载冒烟 + 隔离环境 boot 干净禁用判据 | 仓库根 `node scripts/smoke-load.mjs`(本包在遍历范围内)+ 隔离 profile boot 日志与激活检查 |
| L3 功能面层 | 装载与配置链路 + 归档面板控件盘点 + 危险面确认链(即后文「L3 功能面断言」节断言全集,17 项) | 隔离环境真实页面 + 页面控制台 HTTP 探针 |

执行顺序 L1 → L2 → L3 → L4,前层失败即止。

### L2 装载层

- smoke-load 覆盖:scripts/smoke-load.mjs 自动枚举 packages/ 全部含 package.json 的目录,逐个 dynamic import 其 main,无手工清单。本包 main 为 src/index.js,在遍历范围内:静态 import 的宿主 peer(@deepseek-ai/dsh-storage-domain、@deepseek-ai/schemastery、zod)解析失败或其被引用导出缺失(链接期错误)当场 FAIL;本包命名导出契约由宿主装载判据与 L1 用例覆盖(name 无专项检出,宿主激活失败兜底)。src/client.js 为浏览器单文件自包含格式,不经该脚本加载,其装载性由本层 boot 判据与 L1 client-scope / client-id 补齐;src/core.mjs 与 src/trash.mjs 为 index.js 静态依赖,随 main import 一并覆盖。支持 `--profile` 测 profile 安装副本。
- 隔离环境 boot 判据:activation live + diagnostics findings 0 + boot 日志无本包 pending / 装载错误。
- 干净禁用形态(缺依赖必查):host 半区七项 inject(webServer / workspaceRegistry / sessionQuery / storageDomain / agents / sessions / sessionPersistence)任一不可满足时整体未激活,不拖树、不阻塞 web 启动;timer 为软依赖(ctx.inject(['timer']) 顶层注册,不嵌套 settings 回调),宿主定时服务缺失或调用失败时插件照常激活,仅周期轮停用,`GET /api/session-manager/status` 返回 `periodic.running=false` 携原因文案,面板顶部显示降级提示,session/created 触发与启动补扫不受影响。

### L4 共存层

- 与 dsh-context-manager 同载(现状):设置页同页并存——本包「会话归档」分区(settings.section,order 46)与对端「插件」区「对话增强」卡片互不影响;历史输入浮层、插话撤回、对话 fork 唯一出自 context-manager,本包已无 conversation.input.dock 注入,不存在浮层双份。旧文档「与 context-manager 同插槽共存场景(浮层 z-index)」表述随功能迁出作废,不再测试;两包 settings namespace(`session-manager` / `context`)互不冲突。
- 与 dsh-turn-notify:工作区文件夹运行标记唯一出自 turn-notify(本包已迁出,client 无树 DOM 扫描代码),同装无重复标注、无选择器竞争。
- 与 dsh-settings-nav-icons:client 声明 `{ '会话归档': 'archive', 'dsh-session-manager': 'archive' }`,经 `__navicIcons` 或 `__navicIconQueue` 交给其统一渲染(本插件未就绪时入队,由其启动时排空);同装时设置导航「会话归档」出现图标。
- 与 @mzzsfy/dsh-common-tools:公共通知依赖由本包 dependencies 声明随装,client 装载行由本包 cordis.patch.yml 自带(条目 id `session-manager-dsh-common-tools` 带本包前缀,防多消费插件同装时树内 id 冲突);每个消费插件各自携带装载行,宿主按包名合并成单份 client 模块,本包只带自己那一行;同装其他 toast 消费插件时通知互不串扰。
- 全家桶交叉(当前 20 包):全部插件同装 bundles,页面无 `Failed to load plugins`,仓库根 smoke-load 全 OK,「会话归档」分区与各包设置分区同页可开。

## 维度检查点(补充)

1. **平台删除**:Windows 进回收站、macOS 走对应命令、Linux 删除实现;失败时明确报错,不假装成功。
2. **周期对账**:修改间隔后按锚定语义生效;关闭周期轮只停周期、启动补扫仍在;重启不补跑过期轮次。
3. **台账代际**:台账版本/字段演进可读旧数据;丢失台账时按宿主账本重建;不重复删除。
4. **分页与搜索**:超过 100 条时主列表不翻页、二级视图可分页;搜索框在面板工具区常显且两种视图共用同一个,命中集为全部归档会话(不受首页 100 条与分组限制),大小写不敏感并显示匹配计数。
5. **误归档防线**:`createdAt` 预筛 + 已归档跳过 + stat 活跃度;产物路径以公共 `stat`/`list` 快照 `location` 为真源(旧代 migration-required 也指向真实历史文件),无 stat/list/locate 观测能力、快照无 location 与产物不可读一律跳过;单会话探测异常逐条隔离并计数告警,不整轮 abort;空白判定按产物编码解码(zstd 逐帧解压到两行),解压不可用退回事件数,禁止直接数压缩字节换行。
6. **破坏性动作复核**:删除在真正移走产物前复核归档资格(期间被恢复则 409 中止),级联子会话 detach 失败计入 failed+partial 并保留归档资格;重挂载判定前失效 header 缓存,产物未还原时不被旧缓存放行。
