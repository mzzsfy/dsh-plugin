# dsh-boss-simulator 兼容性测试

包定位:公司管理模拟器。控制室行(`role: control`)注册任务存储(`boss_simulator` 单表 kv)、看板 HTTP 路由(`/api/boss-simulator/*`)、管理员预设与派发/跟随/恢复运行时;`tools-row` 行在 agent realm 注册 `boss_simulator` 业务工具(8 操作),控制室未启动即干净禁用。GUI 为 `main` 槽「公司管理」中央面板 + `sidebar.panellist` 入口,管理员对话为可选 Tab。公共总线 `@mzzsfy/dsh-common-tools` 是硬依赖。

分层与维度定义见 [测试与隔离方法](../../docs/兼容性测试/测试与隔离方法.md)(L1-L4 执行协议)与 [兼容性检查总纲](../../docs/兼容性测试/兼容性检查总纲.md)(D01-D15 维度);宿主升级回归要求见 [DEVELOPMENT/dsh-api-alignment.md](../../DEVELOPMENT/dsh-api-alignment.md) 条款 3。

## 测试分层与执行流程

| 层 | 内容 | 手段 |
|---|---|---|
| L1 单元层 | `test/` 全量:核心编排/查询/设置/任务状态机、board 路由、人类操作入口(创建/授权/派发/同源/体积/幂等)、管理员会话生命周期、工具行与隔离、报表事件归并、跟随恢复、用量台账、client 行为与结构守卫 | 包目录 `npm test`(`node --test "test/*.test.mjs"`),连跑 3 轮 |
| L2 装载层 | 冒烟加载 + 隔离宿主 boot:activation live、diagnostics findings 0、页面无 `Failed to load plugins`、boot.log 无本包行级失败 | `node scripts/smoke-load.mjs` + `node scripts/compat/run.mjs --version <v> --only dsh-boss-simulator --keep` |
| L3 功能面 | 下节断言表,playwright 真机 | 隔离宿主 + `l3-probe`/专用脚本 |
| L4 共存层 | 与 `dsh-common-tools`、`dsh-rs-workflow`(释放预设)、`dsh-settings-nav-icons`、全家桶共启 | 同装 boot + 页面回归 |

执行顺序 L1 → L2 → L3 → L4,前层失败即止。浏览器端到端另有 `test/browser/run.mjs`(不在默认 `npm test` 内;`live-workbench` 用例需独立宿主端口,不与 compat 工位混用)。

## L3 功能面断言

断言在隔离宿主上以 playwright 执行。执行前按[测试与隔离方法](../../docs/兼容性测试/测试与隔离方法.md)设置 `DSH_HOME`、数据目录与端口;管理员/派发链路只指向本次新起的 `echo-upstream`(禁止真实 API)。

### 入口与骨架

| # | 操作 | 预期 |
|---|---|---|
| 1 | 打开宿主页面,等 9s,取 `document.body.innerText` | 无 `Failed to load plugins` |
| 2 | 点侧栏「公司管理」入口,等 2.5s | 中央面板出现任务列表骨架:分组(进行中/待处理/已结束)、状态筛选、搜索框、工作区筛选、「新建任务」主按钮 |
| 3 | 检查数据新鲜度标识 | 总线就绪显示「实时」并带最后更新时刻;未就绪显示「轮询兜底」;手动「刷新」可点 |
| 4 | 空环境(无任务) | 空态文案出现,不报错;「新建任务」仍可用 |

### 任务创建与授权

| # | 操作 | 预期 |
|---|---|---|
| 5 | 点「新建任务」,留空标题直接提交 | 前端拦截并提示,不发请求 |
| 6 | 填标题/目标/范围/验收标准(多行)/工作区/优先级,提交 | 创建成功并落草稿;详情可见「授权」入口;列表出现该任务 |
| 7 | 重复提交同一 `taskId`(页内 fetch 同体) | 返回 409,不产生第二条任务(幂等) |
| 8 | 点「授权」一次 | 授权成功且幂等;再次授权不重复生效 |
| 9 | 点「派发实施」 | 出现二次确认并明确提示开始消耗模型;取消后不产生 Run(只验确认,不真派发) |

| # | 操作 | 预期 |
|---|---|---|
| 10 | 打开任务详情 | 状态与控制、目标与范围、工作区、验收标准、工作项、执行记录(Run/模型/token)、验收结果分区齐全 |
| 11 | 缩窄视口至 640px 再打开详情 | 转为全屏对话框,内容不横向溢出、不裁切 |
| 12 | 已结束任务 | 默认收起的「已结束」分组内可见;展开后状态与结束原因可读 |

### 管理员会话

| # | 操作 | 预期 |
|---|---|---|
| 13 | 切到管理员对话 Tab,首次创建 | 返回/展示管理员会话;不代发 prompt;任务与看板数据不受影响 |
| 14 | 人为使管理员会话失效(隔离环境结束该会话)后重进 | 出现两步「重建管理员会话」;重建后任务与历史记录保留 |

| # | 操作 | 预期 |
|---|---|---|
| 16 | 页内 `fetch('/api/boss-simulator/board')` | 200 且返回任务列表结构(分页/筛选字段在场) |

| # | 操作 | 预期 |
|---|---|---|

| 21 | 并发保存设置(两个标签同时 PUT) | 一方成功,另一方拿到乐观锁冲突(409),不静默覆盖 |
| 22 | 重启隔离宿主后再看板 | 任务/设置/管理员绑定仍在;未结 Run 按跟随逻辑恢复或明确失败;无重复 Run |

## 专项注意

- **危险操作**:派发实施会真实驱动会话并消耗模型额度;隔离工位只指向本次 `echo-upstream`,不点第二次派发,不验收真实模型。授权/结案/全局停止均不可逆或影响面大,断言只到确认弹窗为止。
- **预设依赖**:管理员会话依赖 Agent 预设组合;预设缺失属 D04 条件格,登记环境阻塞而不是包缺陷。
- **存储隔离**:`boss_simulator` 域落在隔离 `DSH_HOME`;不得在真实 `~/.dsh` 上跑创建/派发。
- **时序**:看板数据经总线增量 + 轮询兜底,刷新后断言前等 2.5s;回扫/跟随恢复可能更慢,允许一次重试。
- **判定不越界**:`tools-row` 在控制室未启动时的「无工具」是合法禁用,不判失败;控制室行必须以 patch 方式进入宿主根,临时手工插入不算通过。

L1 三轮全绿 + smoke 通过 + L2 activation live/findings 0/页面无失败插件/无行级失败 + 上表 L3 全部 ✓(条件格按成立形态判)+ L4 全家桶与本包共存对通过。空环境与有数据两种形态至少各执行一次;未执行格记 P,不得以历史轮结论替代本窗口证据。
