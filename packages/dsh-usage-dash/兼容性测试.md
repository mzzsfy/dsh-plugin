包定位:设置内「使用统计」汇总页(6 张汇总卡 + 6 个折叠卡:显示与增强 / 定价规则 / 用量摘要 / 成本护栏 / 异常哨兵 / 省钱沙盘)。天/小时/分钟三粒度 token 与请求统计面板:汇总六卡、26 周活跃热力图、堆叠柱趋势叠加缓存命中率/生成速度/首 token 延迟曲线、模型 donut range/hours/minutes/status/reset/restore/pricing + 成本 7 条 summary/budget/cycle/sentinel/sentinel/ack/whatif/features),宿主拒读档案时降级文件直读恢复统计;client 半区以 `settings.section` 槽注入面板,另在会话底栏 dock 槽以 order 2(官方 activity 0/usage 1 之后)注册 append 费用条目——条目本身是可点击按钮(`aria-haspopup="dialog"`),点击展开估算明细面板,分「当期会话」与「含子代理」两档合计并逐行给出四桶×单价公式,子代理身份取宿主会话列表 `origin === 'subagent'` 的后代;并以 order 3 注册请求详情隐藏锚点(关闭时零节点);官方用时弹窗内另注入最近首 token 平均行与详情入口,详情为独立 modal,不改官方弹窗内容。`cachePrecision` 原位修改官方 usage 胶囊命中率文字、按钮 `aria-label` 与官方弹窗原命中率 `dd` 为两位小数,关闭或卸载时还原;`tokenDetail` 仅在官方 `[data-session-stats-usage]` 用量弹窗 `dl` 末尾追加「输入合计（含缓存）」,且 `cacheWriteTokens > 0` 时再追加「未命中合计（含缓存写入）」,完整千分位显示,不重复官方总量、缓存读写、输出或命中率行;存在子代理时再追加「子代理用量」行与「查看 N 个子代理明细」按钮,点击打开独立 modal 逐子代理展示四桶与费用(摘要行标「仅摘要」,无数据行标「未取到用量」);`recentSpeed` 在官方 `[data-session-stats-details]`「用时与速度」弹窗的输出速度行之后追加「最近输出速度」行,读数来自本插件注册的 `usageDashRecentSpeed` 会话投影:取当前会话最近最多 10 条助手消息,速度为输出 token 合计除 decode 时长合计,单条时长取首 token 到消息完成,与官方「输出速度」同一套 decode 定义,宿主按会话推送;投影不可用时才回落到窗口节点估算(缺首 token 时按端到端含首字等待,零输出只添分母),窗口无可用步骤时不渲染;`replaceSpeed`(子开关,仅统计开启时可见)把官方 activity 胶囊的整会话平均速度原位替换为该读数,文本与 `aria-label` 同步,读数前带「最近」,关闭或卸载还原,默认关;`requestDetails`(默认关)在官方用时弹窗 TTFT 行后追加最近首 token 平均行,并在底部生成「查看最近请求详情」入口,打开独立 modal 展示逐请求 token/时延/费用明细,行内生成速度对短于 100ms 的 decode 窗口显示「—」且不计入表尾均值,数据来自 `usageDashRecentRequests` 投影,关闭时零注入。六项底栏偏好存宿主 settings `usage-dash.statsLine`,client 经 `configForms` 读写(不落浏览器 localStorage)。空用量无插件可见条目,精度或明细单独开启不产生底栏入口。官方未公开用量弹窗扩展 slot,增强依赖 DOM 语义标记;宿主改标记或弹窗归属无法唯一确认时停用相应增强,底栏费用保持独立。官方动作行另注入回合费用芯片。依赖宿主 webServer/sessionPersistence/sessions/storageDomain(顶层 inject)、settings(嵌套 inject,定价能力门面)与 sessionProjections(嵌套 inject,注册 `usageDashModelUsage` 会话小时/模型用量、`usageDashRecentSpeed` 最近输出速度与 `usageDashRecentRequests` 最近请求);client 依赖 slots/locale/configForms(缺失时 cordis 门控整体未激活),服务缺失时干净禁用对应能力,禁止加载崩溃。

## 测试分层与执行流程

| 层 | 内容 | 手段 |
|---|------|------|
| L1 单元层 | test/ 下 `*.test.mjs`(client-eval.mjs 为共享求值工具,非测试),覆盖采集折叠/存储/聚合/计价/路由/存档适配/直读降级/底栏费用与官方用量增强/回合芯片/client 纯函数与双实现同源(清单见下,不锁定测试总数) | 包目录 `node --test "test/*.test.mjs"` |
| L2 装载层 | 全包冒烟加载 + 隔离宿主 boot 干净禁用判据 | 仓库根 `node scripts/smoke-load.mjs`(本包在清单内)+ 隔离 profile 启动 |
| L3 功能面层 | 下节设置面板断言 + 底栏费用与官方用量增强的独立环境回归清单 | playwright 页面断言(隔离宿主) |
| L4 共存层 | dsh-usage-panel(数据源分工:主动查询余额 vs 被动采集用量)、复刻上游 dsh-usage-statistics-panel(底栏槽位,可选场景)、dsh-settings-nav-icons(导航图标)、全家桶交叉 | 同装验证 + 页面级回归 |

执行顺序 L1 → L2 → L3 → L4,前层失败即止。

### L2 装载层

- 冒烟覆盖:scripts/smoke-load.mjs 遍历 packages/ 全部含 package.json 的包并动态 import 各包 main(本包为 src/index.js),OK/FAIL 逐行输出,任一包加载失败即 exitCode 1;支持 `--profile` 切换测 profile 安装副本。本包顶层静态 import @deepseek-ai/schemastery、@deepseek-ai/dsh-storage-domain、zod(peer,经目录逐级兜底解析到 dsh 本体安装目录),解析失败或命名导出缺失当场暴露。src/client.js 非 main,不被该脚本 import——它由宿主 client-modules bundle 经典 script 整源求值装载,覆盖靠本层 boot 判据与 L3。

## 维度检查点(补充)

1. **存档代际**:`open` 句柄代、`inspect` 整读代、宿主拒读词型三态分派;两阶段(open/read)都覆盖;未知代际抛错可读。
2. **降级直读**:zstd 多帧拼接、JSONL 坏行跳过、跨 cwd 定位、磁盘全量会话枚举;直读失败回抛原错。
3. **多宿主共享 DSH_HOME**:旧宿主扫描可能把统计域覆盖成旧 schema,新宿主读到不认识的 schema 清空重建;测试必须隔离 `DSH_HOME` 并登记该风险。
4. **两段式危险操作**:重建只点一次进武装态、3 秒自动解除;回退按钮只断言形态,不触发。
5. **多窗格**:只增强可唯一确认归属的弹窗;无法唯一定位时停用增强,费用仍显示。
6. **口径**:命中率分母(未缓存输入 + 缓存写)、费用只对正计价槽、空数据「—」占位;统计随环境浮动,只断结构不锁数值。

## 判据补充

上表 D01/D05/D06/D08/D11 的检查点全部通过才可宣称本窗口兼容;缓存四桶夹具与多窗格场景未执行时记 P,不得以普通输入/输出样本代替。

已知兼容性边界:

- 归档会话:归档只改变主视图可见性,不改变存在性;本插件统计含归档会话(其消耗真实发生),采集层不读取归档集合做过滤,归档/取消归档不触发重建。夹具见 `test/collector.test.mjs`「归档会话用量照常计入」。
- 宿主紧凑用量模式(`performanceUsage=compact`)下 activity 胶囊是不可展开的 `span`,没有弹窗,读数行不可达,仅胶囊替换生效。
- 胶囊替换按宿主语言的每秒单位匹配(`tok/s`、`jetons/s`、`ток/с`);官方悬浮提示由宿主 props 生成,替换后悬停仍显示官方平均速度,属已知限制。
- 投影状态随会话持久化(最近 10 条配对,约 0.5 KB/会话);宿主 rescan 从事件流重建,重启后读数仍准确。投影缺席(旧宿主或本会话无可读数)时回落客户端节点估算。
- 窗口节点必须带 timing 与合法的 `outputTokens` 才计入读数(缺首 token 的步骤按端到端估算);分页窗口只含近期回合,老会话的读数只反映当前已加载部分。
