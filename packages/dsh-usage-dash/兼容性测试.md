# dsh-usage-dash 兼容性测试

包定位:设置内「使用统计」汇总页(6 张卡)。天/小时/分钟三粒度 token 与请求统计面板:汇总六卡、26 周活跃热力图、堆叠柱趋势叠加缓存命中率/生成速度/首 token 延迟曲线、模型 donut 与列表、回扫状态与重建/回退、底部信息栏偏好卡、分时段定价规则编辑器。host 半区采集 session/event 折叠为样本落 `usage_stats` 存储域(天桶永久/小时桶 15 天/分钟桶默认 7 天),经 webServer 暴露 `/api/usage-dash/` 下 7 条 exact 路由(range/hours/minutes/status/reset/restore/pricing),宿主拒读档案时降级文件直读恢复统计;client 半区以 `settings.section` 槽注入面板,另接管会话底栏 `stats` 槽并在官方动作行注入回合费用芯片。依赖宿主 webServer/sessionPersistence/sessions/storageDomain(顶层 inject)与 settings(嵌套 inject,定价能力门面),服务缺失时干净禁用,禁止加载崩溃。

| 层 | 内容 | 手段 |
|---|------|------|

| L3 功能面层 | 入口与分区 3 项 + 汇总六卡 2 项 + 数据源链路 2 项 + 视图联动 3 项 + 空态 1 项 + 图表区 2 项 + 偏好卡 2 项 + 定价编辑器 1 项 + 状态折叠层 2 项(共 18 项,即下节断言全集) | playwright 页面断言(隔离宿主) |

### L2 装载层

- 冒烟覆盖:scripts/smoke-load.mjs 遍历 packages/ 全部含 package.json 的包并动态 import 各包 main(本包为 src/index.js),OK/FAIL 逐行输出,任一包加载失败即 exitCode 1;支持 `--profile` 切换测 profile 安装副本。本包顶层静态 import @deepseek-ai/schemastery、@deepseek-ai/dsh-storage-domain、zod(peer,经目录逐级兜底解析到 dsh 本体安装目录),解析失败或命名导出缺失当场暴露。src/client.js 非 main,不被该脚本 import——它由宿主 client-modules bundle 经典 script 整源求值装载,覆盖靠本层 boot 判据与 L3。
- 隔离环境 boot 判据:bundle 经 `dsh plugin add @mzzsfy/dsh-usage-dash` 注入 profile 后需重启一次宿主完成首装载(bundles 表变化不支持热重载);判据 = activation live + diagnostics findings 0 + 页面无 `Failed to load plugins`。
- 干净禁用与降级形态表(出现以下形态属预期,不判失败,但须核对与宿主实际能力一致):

| 条件 | 行为 |
|---|---|
| 宿主缺顶层 inject 任一服务(webServer/sessionPersistence/sessions/storageDomain) | fiber 不激活,插件整体未注册,不 pending 拖死 boot |
| 宿主缺 settings(嵌套 inject) | 仅定价写入能力缺席:GET /api/usage-dash/pricing 回空表零 revision(编辑器呈空表 ready 形态)、POST 拒 503(保存时编辑器内报错);分钟桶保留回落默认 7 天;采集/查询/面板照常 |
| client 侧 require('react') 失败 | 返回空插件(inject 空、apply 空实现),不注册任何 UI |
| client 侧缺 slots 或 locale 服务 | 服务声明交 cordis 门控整体未激活,宿主升级即自愈 |
| 宿主无 conversation.composer.dock 或 conversation.chat.assistant-actions 插槽 | 对应注入点 console.warn 后禁用该功能,设置面板不受影响 |
| 宿主 persistence API 两代形状均不识别 | 回扫 list 抛错写入 status.error,面板状态行呈现,不崩溃 |
| usage_stats 域打开失败 | store 进入降级态:ready 可等待,操作按调用失败,失败计入 recordFailures 与异常日志,绝不逃逸拒绝拖垮宿主 |

- 启动回扫:激活后异步执行分钟/小时桶保留清理与全量回扫(并发 4);空环境数秒内完成,大历史环境完成前统计偏少属预期,回扫状态与异常经 `/api/usage-dash/status` 与面板状态行可观测。

### L4 共存层

- @mzzsfy/dsh-usage-panel(本仓库全家桶包,账号余额面板):数据源分工互补——usage-panel 为主动查询型(设置页「账号余额」分区,配置 DeepSeek/OpenRouter/Kimi/智谱/MiniMax/NewApi 等平台账号后定时拉取各平台余额/额度 API);本包为被动采集型(消费会话 usage 事件与存档回扫,统计真实消耗)。两者无功能交集:路由(`/api/usage-panel/*` 与 `/api/usage-dash/*`)、设置分区(id=usage-panel、order 40、label「账号余额」 vs id=usage-dash、order 45、label「使用统计」)、存储域与导航图标声明互不冲突,同装是全家桶常见组合。断言:同装下两分区并存且各自可进、相互 activation live、页面无 `Failed to load plugins`。
- 复刻上游 dsh-usage-statistics-panel(HaoyueQin 的 npm 第三方包,非本仓库包,不随全家桶安装):若环境单独装载它会与本包争抢会话底栏 `stats` 槽——槽注册表对同 id 同 priority 直接抛错,本包以 priority -2 注册(上游 -1,更低者渲染)遮蔽上游,同装本包胜出,卸载本包重启宿主后上游恢复;两者数据 API 与存储域均不冲突,同装仅重复采集。此为可选场景,默认全家桶验证不含它。
- dsh-settings-nav-icons(导航图标):client 半区声明表盘图标 `{ '使用统计': 'gauge', 'Usage': 'gauge', 'dsh-usage-dash': 'gauge' }`(键覆盖中英分区名与包名,与他包键不冲突),经 `window.__navicIcons.register` 注册或 `__navicIconQueue` 入队由其排空。同装时设置导航「使用统计」项带图标;该插件缺失时仅图标不渲染,导航项仍可点,不判失败。
- 全家桶交叉:设置分区 order 45 与其他分区按 order 排序共存;样式注入带 `data-plugin=@mzzsfy/dsh-usage-dash` 契约(client-id 测试锁定),任一其他插件 HMR 重建后本包样式不得丢失;回扫读取宿主全部会话档案(含降级文件直读),同宿主其他插件会话的用量一并入账属预期(只读,不写他包数据)。
- 共存底线:任意插件组合下页面无 `Failed to load plugins`;全家桶共启后本包 activation live、diagnostics findings 0、设置分区与会话侧两个注入点均不被他包挤掉。

## 专项注意

- 卡片数值随隔离环境数据浮动,只断言键名与结构存在,不断言数值;条件形态不作硬断言:「最常用模型」空数据显示「—」、Tokens 卡头部估算费用行(≈ 数值)仅在配置定价规则且有命中数据时出现、「金额」口径开关仅存在正计价数据时渲染(未配价或全量未计价不出现,防误导设计,不是缺失)。
- 统计页读宿主存档 API,数据大时渲染慢,断言前已含 2.5s 等待,偶发不足可重试一次。
- 危险操作(两段式按钮与写入入口,点名与原因):
  - 「重建」:第二次点击即 POST /api/usage-dash/reset 清空统计域并全量重扫,统计清零且回扫耗 CPU;断言 #18 只点一次进武装态,3 秒超时自动解除,严禁 3 秒内连点,任何重试逻辑不得对文案为「确认重建」的按钮再点。
