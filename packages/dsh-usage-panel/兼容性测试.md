# dsh-usage-panel 兼容性测试

包定位:多平台 LLM 账号余额与额度面板,设置页 settings.section 分区「账号余额」(id usage-panel,order 40)。手动配置多组账号(上限 20 个,API 地址 + Key),定期(全账号统一 10 分钟)自动查询余额/额度,读数进度条与悬浮趋势 sparkline,历史快照落盘;刷新评估越过逻辑点(用量阈值穿越/余额阈值穿越/窗口重置)时经 webhook、dsh-im、页内 toast 三通道通知。host 半区(`src/index.js`)以 webServer 注册 9 条 `/api/usage-panel/*` 路由,通知规则持久化走 settings `usage-panel` 命名空间,账号与快照落 `~/.dsh/dsh-usage-panel/`(可 env 覆盖);client 半区(`src/client.js`)注册设置分区、激活即挂页内通知长轮询(不依赖面板打开)、声明导航图标。依赖面:webServer 顶层必需(缺失即 fiber 不激活干净禁用);settings/timer/dshIm 全软依赖(缺失各自降级,不阻塞装载);client 侧 slots 与 react 必需,`@mzzsfy/dsh-toast` 可选消费(占位条目由 session-manager 代挂,缺失降级 console)。

## 测试分层与执行流程

| 层 | 内容 | 手段 |
|---|------|------|
| L1 单元层 | test/ 下 12 个 `*.test.mjs`,覆盖平台解析/轮询调度/历史快照/持久化守卫/通知评估/路由接线/双实现同源/client 结构守卫(清单见下) | 包目录 `node --test "test/*.test.mjs"` |
| L2 装载层 | 全包冒烟加载 + 隔离宿主 boot 干净禁用判据 | 仓库根 `node scripts/smoke-load.mjs`(本包在清单内)+ 隔离 profile 启动(必带 `DSH_USAGE_PANEL_DATA_DIR`) |
| L3 功能面层 | 入口与骨架 5 项 + 账号配置流 6 项 + 通知规则卡 2 项 + 宿主路由直查 2 项(即下节断言全集,共 15 项) | playwright 页面断言(隔离宿主) |

### L2 装载层

- 冒烟覆盖:scripts/smoke-load.mjs 遍历 packages/ 下全部含 package.json 的目录(symlink/junction 一并收),逐个动态 import 各包 main——OK/FAIL 逐行输出,任一包失败即 exitCode 1;`--profile` 切换为遍历 profile node_modules 测安装副本。本包 main 为 src/index.js,在清单内:宿主半区顶层依赖(@deepseek-ai/schemastery 等)解析失败或自身命名导出损坏当场暴露。src/client.js 非 main,不被该脚本 import,其装载由本层 boot 判据与 L3 覆盖。
- 隔离环境 boot 判据:bundle patch 在 profile root 插入 id=usage-panel 行,经 `dsh plugin add @mzzsfy/dsh-usage-panel` 注入后重启一次宿主完成首装载;判据 = activation live + diagnostics findings 0 + 页面无 `Failed to load plugins` + 同源 `GET /api/usage-panel/settings` 返回含布尔 pollArmed 的 JSON(路由在场)。顶层 inject 仅声明 webServer:旧宿主缺 webServer 时 fiber 不激活即干净禁用,不 pending 拖死 boot。
- 软依赖降级形态表(出现以下形态属降级预期,不判失败,但须核对与宿主实际能力一致):

| 宿主能力缺失 | 面板/路由形态 |
|---|---|
| timer(嵌套 inject 等待,缺失不阻塞装载) | pollArmed=false;面板顶部警示「自动轮询未运行(宿主定时服务不可用);手动查询不受影响。」,手动查询与全部配置不受影响 |
| settings | 通知配置读写不可用(notify-config POST 400「settings 服务不可用」);账号配置与查询不受影响,通知评估按全局默认(关)短路 |
| dshIm(运行期探测) | 通知卡显示「dsh-im 未安装,IM 通道不可用」;im-targets 503;test-im 如实返回失败明细 |
| @mzzsfy/dsh-toast(client 模块表可选消费) | 页内 toast 通道整段停用(长轮询不启动),操作反馈降级 console.warn,面板与查询不受影响 |

- 启动隔离宿主必须带 `DSH_USAGE_PANEL_DATA_DIR=<临时目录>`:不设则数据目录落到默认 `~/.dsh/dsh-usage-panel`,与生产实例共用——GET 读到生产账号、保存/查询会把测试数据(含账号 Key 明文)写进生产 accounts.json(测试不是只读操作)。env 注入逻辑有单元测试与源码常量锁定,空白值回默认路径。

## L4 共存层

- dsh-usage-dash(数据源分工,非依赖):本包为主动查询型——数据源是各平台余额/额度上游 API,落 `~/.dsh/dsh-usage-panel/`;usage-dash 为被动采集型——扫宿主会话存档聚合 token 统计,落 storage-domain。路由前缀 `/api/usage-panel/*` 与 `/api/usage-dash/*` 不冲突,设置分区(「账号余额」order 40 /「使用统计」)并存互不接管。同装验证两分区各自渲染、互不干扰。易混提示:会话底栏/消息动作行内的 tok、费用现象属 usage-dash 功能面,勿归本包误判(见专项注意断言保留记录)。
- @mzzsfy/dsh-toast(反馈依赖,package.json 显式 dependencies):client 半区可选消费——模块表无 toast 即降级 console.warn,不挂死不报错(占位条目由 session-manager 唯一代挂)。「在场/缺失」两形态均合法:在场时操作反馈右下角浮出,缺失时反馈走 console;均不判失败。
- dsh-settings-nav-icons(导航图标):client 半区声明双键 `{ '账号余额': 'wallet', 'dsh-usage-panel': 'wallet' }`,经 `__navicIcons` 注册或 `__navicIconQueue` 入队(本插件未就绪时入队,由其启动时排空)。同装时验证设置导航「账号余额」项带钱包图标;该插件缺失时仅图标不渲染,导航项仍可点,不判失败。
- dsh-im(IM 通知通道,运行期 `ctx.get('dshIm')` 探测):未装时 IM 通道干净不可用(见 L2 降级表),通知其余通道与面板不受影响;同装时通知卡出现 IM 投递区,断言 #13 按分支判。
- 设置分区共存:settings.section 分区 id=usage-panel、order 40、label「账号余额」,与其他插件分区按 order 排序;`/api/usage-panel/*` 九条路由与 settings `usage-panel` 命名空间为本包独占,全家桶下无注册冲突。
- 样式契约:样式注入自带 data-plugin=@mzzsfy/dsh-usage-panel(client-id 测试锁定);全家桶下任一其他插件 HMR 重建后,本包面板样式不得丢失(样式被误删表现为控件裸排,命中即回归)。
- 共存底线:任意插件组合下页面无 `Failed to load plugins`;全家桶共启后本包 activation live、diagnostics findings 0。

## 专项注意
