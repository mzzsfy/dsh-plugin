# dsh-context-manager 兼容性测试

包定位:历史输入浮层(Alt+↑ 唤起,范围导航/搜索/收藏回填)+ 插话撤回(未应用的插话撤回至输入框)+ 对话 fork(重写式分叉/家族版本环/进行中轮分叉/自动重发)+ 设置页「插件」区「对话增强」启停卡片(四开关)。宿主半区六条 `/api/context/*` 路由与 settings `context` namespace;client 半区经 `conversation.input.dock` 插槽注入三个 dock(历史/撤回/fork),样式注入自带 `data-plugin` 标记;公共通知依赖 dsh-toast 可选消费(缺失通知置空),client 对 `remote.session` 等版本脆弱面点分 inject 交 cordis 门控。

## 测试分层与执行流程

| 层 | 内容 | 手段 |
|----|------|------|
| L1 单元层 | 仓库 test/ 13 文件 131 用例 | 包目录 `node --test "test/*.test.mjs"` |
| L2 装载层 | smoke-load + 隔离环境 boot | 仓库根 `node scripts/smoke-load.mjs`;隔离 boot 日志与激活检查 |
| L3 功能面层 | 即下节回归子集(9 项) | 隔离环境真实页面 + HTTP 探针 |
| L4 共存层 | 同插槽/同页共存与全家桶 | 多插件同载 + 页面断言 |

- L1 分组覆盖点(静态清单,已抽查确认):
  - 纯逻辑层 core + core-family(39 用例):输入提取、聚合去重与首条保护、搜索、fork 错误文案与重试文本、家族投影与版本环;
  - 宿主半区 index + history-cache(32 用例):六条路由行为、405/400 守卫、系统级错误收敛、settings 持久、subagent 排除与窗口、stat 指纹零解压、工作区缓存指纹复用与文件名安全、prompts 归一化;
  - 镜像与源码契约 parity + client-help + client-scope + client-id + client-switch-guard(19 用例):client/core 镜像同源、API 路径互为镜像、响应信封解包、client 整源求值零全局泄漏、注册 id 为完整包名、样式 data-plugin、cx-switch 选择器契约;
  - client 功能面 client-steer + client-fork + client-fork-enhance + client-fork-family(41 用例):撤回注入与干净禁用、fork 门控与轮映射、进行中轮与自动重发降级、家族环降级。
- L2:smoke-load 无手工清单——脚本自动枚举 packages/ 全部含 package.json 的目录逐个动态 import main,本包自动覆盖(历史疑问「context-manager 未入 smoke 清单」不成立,清单本就不存在);其覆盖面是 host 半区模块可加载性,client 打包形态由 boot 断言与 L1 client-scope 补齐。boot 判据:无本包 pending/装载错误;旧宿主缺依赖时表现为干净禁用(整体未激活、不拖树、不阻塞 web 启动)。
- L4:与 session-manager 同载(其已迁出历史输入/插话撤回/对话 fork,现为自动归档能力;settings namespace `session-manager` 与本包 `context` 无冲突);turn-notify 运行标记共存;全家桶 14 包交叉(全部 smoke OK + 页面无 `Failed to load plugins`)。

执行顺序 L1→L2→L3→L4,前层失败即止。

## L3 兼容性回归断言(9 项,本文件自足)

| # | 项 | 操作 | 预期 |
|---|-----|------|------|
| 1 | 装载与样式 | 冷启动看 boot 日志;页面控制台执行 `document.querySelectorAll('style[data-plugin="@mzzsfy/dsh-context-manager"]').length` | boot 无本包 pending/装载错误;控制台无本包报错;计数恰为 1 |
| 2 | 设置分区开关数 | 设置页「插件」区展开「对话增强」卡片,数 `.cx-switch` 行,逐行悬停 | 恰 4 个开关行,均为 cx-switch 形态(label 内 `input[type="checkbox"]` + `.cx-switch__track`/`.cx-switch__thumb`),label 依次为「历史输入浮层(Alt+↑)」「插话撤回」「对话 fork」「分叉后自动重发」,各行悬停有 title 行为说明 |
| 3 | 浮层打开 | 输入框按 Alt+↑ | 浮层打开,顶栏范围标签「当前会话」+ 搜索框 + 键位提示;有历史数据时列表时间倒序,无数据显示「该范围内还没有历史输入」而非报错 |
| 4 | 浮层停用 | 设置卡片关「历史输入浮层」开关,刷新页面后按 Alt+↑;再恢复启用复按 | 变更刷新页面生效:刷新后 Alt+↑ 无响应,浮层与零高度锚点整体不渲染;恢复后正常(插话撤回/fork 开关同构,全量归深测) |
| 5 | 撤回入口存在性 | 打开任一常规(非 subagent)会话,控制台查 `document.querySelector('.cx-steer-host')` | 元素存在(`display:none` 零占位),证明撤回 dock 已挂载且 updateQueue 绑定通道可用;真实插话气泡上的图标注入与撤回动作归深测 |
| 6 | fork 入口与注入 | 打开含多个已完成轮的常规会话,控制台查 `.cx-fork-host` 与用户气泡操作排 `[data-cx-fork]` | 零占位宿主存在;锚点窗口内非首轮文本用户气泡(本场景全部轮已完成,`[data-chat-flow-kind="user"]`)操作排出现分叉按钮,首轮气泡没有(超长会话窗口外更早轮无按钮属预期,归深测) |
| 7 | 启停路由 GET | 服务端探针(带 Origin 与 Referer 头;页面控制台 fetch 同源自动满足)依次 GET `/api/context/history-enabled`、`/api/context/steer-recall-enabled`、`/api/context/fork-enabled`、`/api/context/fork-auto-resend-enabled` | 各返回 200 `{"enabled":<布尔>}`(前三默认 true,自动重发默认 false;此前被切换过则断言键存在且为布尔) |
| 8 | 方法白名单 | 带 Origin/Referer 直调 `PUT /api/context/inputs`;`GET /api/context/prompts/toggle` | 均 405 `{"error":"method not allowed"}` |
| 9 | 共存 | 与 session-manager(及 turn-notify)同载,浏览主界面与设置页 | 页面无 `Failed to load plugins`;session-manager 归档分区与本包「对话增强」卡片同页并存互不影响;历史浮层唯一且仅出自本包(对端已迁出历史输入,无双份浮层);控制台无本包报错 |

探针说明(内联):dsh 本体 0.1.2-rc.1 起 token 认证宿主对服务端直调缺 Origin/Referer 的请求会被 webAuth 拦截返回认证页,故服务端探针必须带头;页面控制台 `fetch` 为同源请求自动满足,推荐优先使用。回归的启停项只做 GET 非破坏断言,POST 切换与持久归深测,避免污染后续断言。

## 专项注意

- 专项计划存在过期描述(设置分区名/用例数),以其执行深测前先对照本文档回归表与 src 校准。
- 端口:专项计划历史约定 3083;并入整体计划执行时统一 9191,按当轮环境选择,生产端口(3080)不碰。
- fork 重写式语义(分叉边界/轮内插话/open 失败回填)在专项计划标「待复测」:兼容性回归不阻塞其复测,复测安排在深测轮。
- 人工/环境受限项:IME 组合输入需真人输入法参与,自动化无法模拟(实现为 isComposing 首位守卫);真实插话撤回需会话运行中发送插话,隔离环境静态样本不满足——撤回顺序与禁用门控已由单测覆盖,实机项留日常使用确认。
- 误判防范:时序相关断言(开关延迟到达、注入门控、停用生效)必须冷启动验证,不信热重载表现;重启前按命令行杀净旧宿主进程,防请求打到旧进程得出「改了没生效」假结论;boot 日志乱码按 UTF-8 读取;控制台偶发的其他插件报错为环境噪音,断言只针对本包;隔离环境无历史数据时浮层显示空态文案,勿把空态误判为功能失效。
