# dsh-turn-notify 兼容性测试

包定位:会话轮次结束通知(设置「消息通知」节 + webhook host 直发)。host 半区观察 `session/event`(含 `approval/asked`),把回合结果归入六类(任务完成/任务出错/被中断/等待审批/AI 提问/达到上限),按事件→通道路由(kindRoutes)送达七通道:`sound`/`system`/`toast`/`blink`/`webhook`/`im`/`host`(页内提示音为 toast 衍生通道)。webhook、IM、宿主桌面通知由 host 直发(超时 10 秒,fire-and-forget);浏览器通道经内存投影(环形 20 条/60 秒过期,不落盘)由公共 WS 变更通知驱动 client 合并快照拉取,IndexedDB 事务认领保证多窗口只响一次。设置面为 settings.section 分区「消息通知」(order 41,settings 命名空间 `turn-notify`),client 经 11 条 `/api/turn-notify/*` 路由读写配置、音效库、测试点火与 macOS 桌面唤起。独立功能面三件:会话行高亮(tn-sess-hl 六分类色脉冲)、点击直达(sessionId 身份导航,见 notification-click 测试)与工作区文件夹运行标记(自 session-manager 迁入,已确证,见断言 #7)。

### L2 装载层

- 冒烟覆盖:scripts/smoke-load.mjs 遍历 packages/ 全部含 package.json 的包并动态 import 各包 main(本包 src/index.js),本包在清单内:顶层依赖 `@deepseek-ai/schemastery` 缺失或模块级错误当场 FAIL(其余顶层 import 均为 node 内置模块);支持 --profile 测 profile 安装副本。src/client.js 非 main 不被该脚本 import,其装载由本层 boot 判据与 L1 的 parity/flow/hmr-heal/switch-guard/client-id 源码级测试覆盖。
- 隔离环境 boot 判据:bundle 经 `dsh plugin add @mzzsfy/dsh-turn-notify` 注入 profile(cordis.patch.yml 单行 insert,id=turn-notify)后重启一次宿主完成首装载;判据 = activation live + diagnostics findings 0 + 页面无 `Failed to load plugins` + `GET /api/turn-notify/config` 返回 200 且响应含 `folderRunningEnabled` 字段(顺带确证运行标记配置面 host 侧可用)。
- 干净禁用形态:顶层 `inject = ['webServer']` 点分声明,宿主缺 webServer 时 fiber 不激活即整体干净禁用,不 pending 拖死 boot;settings 经 `ctx.inject(['settings'], ...)` 嵌套声明,缺失时仅跳过设置节注册,事件观察与路由照常;可选依赖全部运行期探测——dshIm 经 `ctx.get('dshIm')`(IM 通道静默弃投)、session-title 服务(标题回落首条消息)、toast属性读取缺失时页内提示通道禁用（common-tools模块本身为硬依赖，总线不可缺）。任一可选依赖缺失均不判失败。
- 环境副作用:音效库目录 `~/.dsh/dsh-turn-notify/sounds` 惰性创建,投影不落盘;本流程测试全程只读,不产生宿主侧数据(唯一写面是浏览器 localStorage 本机键与误触测试按钮的外发,后者被专项注意禁止)。

## L3 功能面断言

断言于隔离宿主上以 playwright 执行;选择器与文案均对照 src/client.js 校准。沿用既有等待约定:页面加载等 9s、导航点击后等 2s、渲染断言前等 2.5s。全程只读:一切写操作(保存/清除/开关切换/pill 点击/映射 select/上传/删除/重命名/各测试点火按钮)一律不做——分类 pill 与开关点击即存(立即 POST config),测试点火按钮产生真实外发(见专项注意)。通知触达链路(发声/弹窗/高亮/直达/二次提醒的运行时行为)由 L1 的 flow/event-wiring/notification-click 覆盖,页面级不主动制造回合结束。

### 页内通知样式专项验收

仅在新建隔离浏览器上下文与隔离宿主中执行,允许变更该上下文的本机样式偏好与无声预览;不点声音、系统、宿主、webhook、IM测试按钮。数据与截图按本轮隔离测试记录落临时目录，结束后仅清本轮资源，不访问生产profile或真实LLM。

| Given | When | Then |
|---|---|---|
| 亮色或深色宿主主题 | 分别选择标准浮条与主题卡片并预览 | 正文及第二行小结清晰可读,前景与合成背景对比度至少 4.5:1;无声音和外发请求 |

## L4 共存层

- @mzzsfy/dsh-common-tools(公共依赖,package.json 显式 dependencies):模块表挂载由session-manager代挂。本包client硬依赖公共WS总线与快照刷新能力；仅toast能力可选，缺失时操作反馈降级console.warn、页内通道禁用，其余通道照常。空闲不周期拉HTTP，活跃刷新单飞限频，末个owner退出中止快照且不复活。
- session-manager(服务快照消费):本包 client 顶层 `inject = ['slots', 'sessions', 'workspaces', 'uiWorkspace']`,运行标记另以子 fiber 注入 `jobs` / `uiSession`,会话导航另以子 fiber 注入 `uiWorkspace` 按实例登记(factory 共享 Map,点击时取最后激活且存活的实例,卸载只删自己的登记,存活实例接管,最后实例退出后不复活旧导航)。聚合只读 `sessions.list` / `workspaces.list` / `uiSession.sessionStatus` / `jobs.state`,并为可见主会话及本地子树调用官方引用计数 `jobs.watchRows(id)`;不调用任务输出观察、不改写服务快照。子会话须遍历 `byId` 而非仅 `ids`,按 `origin=subagent` 和 `parentId` 归根;即时状态优先于惰性子行的 running;后台任务须匹配 owner 且状态为 running/stopping。归档、退出分组与卸载释放名册和订阅。所需活动服务缺失时仅标记不激活,通知仍装载;外部委托无本地运行态、名册初载/断流无就绪位属明确覆盖边界。会话行高亮按官方data-row-key=session:<id>严格唯一匹配；导航经uiWorkspace.openSession(sessionId)，当前会话按sessions.list retainedBy.mainView判定。slots 注册 id=turn-notify、order 41 与其他分区无冲突。同装验证运行标记与 session-manager UI 不互相覆盖。
