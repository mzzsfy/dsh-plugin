# 更新日志

## 0.3.2（2026-11-05）

一键启用不再丢失可用市场，搜索提速一个数量级。

### 性能

- **搜索合并请求**：联想端点为全市场端点，此前按市场逐个串行请求（八市场=八次相同请求），实测 7-8 秒；改为每个实例只请求一次全市场候选再按市场归属分发。
- **搜索结果缓存**：同一查询 60 秒内直接复用结果，退格重输零远端开销；并发同词请求合并为一次在途调用。
- 实测：首次 199-1020ms，重复查询 1ms。
- **缓存与索引全部有界**：搜索结果 64 条、候选表 200 条、在途合并 32 条、探针缓存 512 条、美股代码索引 500 条，超限淘汰最早条目；探针缓存过期条目即时淘汰；`catalog.stats` 可观测当前占用。

### 修复

- **探针失败按目标粒度剔除**：一键启用检查时，失败目标只摘除该目标而非整条路由；主源不可用自动提升首个可用备源（例：腾讯声明支持美股 K 线但实际不支持，此前会把整条 `xnas-kline` 删掉，连带丢掉可用的东财备源，导致美股/港股详情页「未配置该市场的数据来源」）。全部目标不可用才删路由。
- **备源数量上限**：适配器声明的能力×市场矩阵是多对一关系，此前把全部支持者塞进备源列表会超出 schema 上限导致整份配置被拒（三个以上数据源时一键启用「什么都没发生」）；现在只取首个备源。
- **目录与搜索不配备源**：schema 限定只有报价与 K 线支持备用源，此前 bootstrap 给目录/搜索也生成 failover，造成保存被拒。

## 0.3.1（2026-11-04）

一键可用与设置分域。

### 变更

- **一键全能力自举**：设置「市场与能力」新增「一键启用全部能力（自动检查并保存）」——按已启用数据源适配器声明的能力×市场补全全部缺失路由（行情/K线/目录/搜索），自动分批检查（denied 探针降级剔除，部分可用优于整体失败）并保存；K线 NO_ROUTE 错误条引导钮改「一键开启」走同链路。配置数据源后一键即全通，无需逐项研究。
- **设置页三段 Tab**：手风琴改「数据源/市场与能力/显示偏好」三分区，各自独立保存（③显示偏好即改即存）；草稿互不拖泥带水（保存一侧时另一侧取已保存值）。
- **浏览市场按钮按已配置目录路由显隐**：仅显示落库 catalog 路由覆盖的市场（声明≠探针可用），未配置市场不再给出点了就报错的按钮。

- **详情抽屉加宽**：侧边抽屉 560px 改 80vw（屏幕 4/5），K线与明细一览无余。

### 修复

- **Tab 样式注入损坏**：样式插入吃掉选择器分隔符致 header flex 布局规则整体失效（导航换行回归），恢复分隔符并全量扫描 CSS 选择器完整性。
- **browse 点行白屏**：详情视图切换误清 browse 峰览状态（updateView overlay 语义修正）。

## 0.3.0（2026-11-02）

设置可递进、上游可观测、API 反代可用。

### 修复

- **五轮变更对抗审查（review 协议，5 阻断全修复，9 建议采纳 7/部分 2，复审新阻断 B6 一并修复）**：成本表单 NaN 静默清空改为 isFinite+正数校验就地报错；成本/分组草稿跨证券残留（切详情不清）导致串写——三处切换入口统一清草稿；节头持仓盈亏由百分比求和（随只数放大）改为等权均值；键盘导航索引与分组分段 DOM 序错位改为按渲染序导航；分组分配补详情「设分组」入口（原仅 API 可达；空串/纯空白=移出分组，重命名保持非空）；遮罩穿透限抽屉（模态穿透是隐性突变）；组名/重命名收紧非空白校验；CHANGELOG 悬空标题与重复动画声明清理。

### 变更

- **自选分组**：条目支持单分组标签（`group`/`groupRename`/`groupRemove` 操作，组名 1-12 字非空白，重命名/解散原子批量更新）；详情抽屉「设分组」表单分配/移出；手动顺序视图按组分段——组头行显 `组名 · N 只 · X 涨 Y 跌` 统计并支持折叠（aria-expanded 同步）、重命名与解散（折叠状态随组变更清理）；未分组零侵入（无组头行）；置顶区不受分组影响恒顶；涨幅/跌幅全局排序时不分区；键盘导航按渲染段序（分组后仍逐行正确）。

- **持仓成本与盈亏（对标 Leek-Fund 核心能力）**：自选条目支持成本价（新增 `cost` 操作，正数或空），列表新增「持仓盈亏」列 `(现价-成本)/成本%`（未设成本显示 —），节头概览追加持仓合计盈亏（仅计已设成本者，1 位小数），详情抽屉侧栏新增成本价设置/清除表单与盈亏块（盈亏额+盈亏%+成本）。

- **主页降噪与设置手风琴（对标 Leek-Fund 交互模型）**：数据源健康横幅仅在异常（实例故障或被禁用）时出现，健康态主页零运维横幅、列表即主角；组合概览并入「自选 · N」节头行（不再占独立横幅带）；运维摘要（N/M 源启用·K线市场数）挪进「更多」菜单；设置模态的「市场与能力」「显示偏好」折叠为手风琴摘要行（显示 `4 市场 · 12 项路由`、`红涨绿跌 · 15秒刷新` 等实时状态），打开后第一屏只余数据源实例。

- **自选页好用性收敛**：列表头部新增组合概览（N 只 · X 涨 Y 跌 · 合计涨跌额）；表格补涨跌额列，来源/延迟降权为健康徽标（✓/警示词，全文 hover 可读）；详情抽屉内新增「上一只/下一只」邻移（对比持仓免关闭往返）；抽屉开启时点击遮罩下可见的自选行直接切换详情（elementsFromPoint 穿透，抽屉保持开启）。

- **交互分层重构**：证券详情改为右侧抽屉浮层（底层列表保留可见，Esc/遮罩/关闭钮统一关闭，关闭即回进入前视图，替代原「返回市场/返回自选」双态按钮）；设置改为模态浮层；K线周期升级为 Tab 语义（role=tablist/tab+aria-selected，刷新钮移出 tab 组）；顶部导航按使用频率分层——自选/市场/搜索三主区切换+刷新常驻，暂停采集/设置/返回对话收进「更多」菜单；弹层实现焦点移入/Tab 困住/关闭还原/背景滚动锁定与入场动效（ease-out，仅 transform/opacity），遮罩与阴影改引宿主语义变量（去除自造别名与字面阴影色）。

### 新增

- **搜索候选「看一眼」**：搜索结果行名称区点击直接进详情（同 browse 点进路径），与选择/加自选正交；refresh 支持 `securities` 对象形态（id+exchange+code），港美股候选（不在目录）不经目录解析按完整身份直拉行情。
- **市场浏览可点进详情**：浏览市场行点击直接打开该证券详情（行情/K线全可用，无需先加自选）；按需拉取该证券报价（collector 证券解析链扩展：自选→目录缓存兜底）；非自选详情以「加自选」为主操作并提供「返回市场」，别名等自选管理仅在自选详情呈现——自选定位回归"市场快捷方式"。
- **市场概览**：浏览市场页头部显示代表指数实时点位与涨跌幅（沪=上证指数 000001，深=深证成指 399001），随 browse 响应一并返回（`browse.overview`），指数拉取失败静默隐藏不阻断目录浏览；指数不入自选/目录，走东财 quotes 管道直拉并经延迟派生。
- **接口反代（API 端点覆盖）**：数据源实例可按适配器端点键替换请求地址（东财五个端点/腾讯两个端点，descriptor `endpointKeys` 下发标签），自建反向代理或镜像只需原样转发同路径；留空回官方默认。适配器端点表化（`DEFAULT_ENDPOINTS`+`endpointOf(ctx,key)`）。
- **实例级 HTTP 代理出口**：`providers[].proxy`（`http(s)://[user:pass@]host:port`），executor 按 URL 惰性缓存 undici ProxyAgent 注入 ctx.fetch；包不可用时该实例静默降级直连。
- **上游可观测**：executor 记录每实例最近 20 条请求环形日志（时间/能力·适配器/状态/耗时），快照 `providerStatus[].recentRequests` 下发；设置页实例卡「运行状态」折叠组展示，summary 标注代理态。
- **设置页递进信息架构**：「① 数据源 → ② 市场与能力 → ③ 显示偏好」三区块；实例卡内适配器一句话说明（descriptor `description`）、高级预算折叠、接口反代与运行状态分组。
- **列表概览横幅**：常驻显示启用数据源数与最近请求失败实例，「管理」直达设置页；K 线就绪市场数随横幅展示。

### 变更

- snapshot `providerStatus[]` 扩展 `proxy`/`endpointsCovered`/`recentRequests` 字段（向后兼容追加）。
- **延迟真实化**：适配器未声明延迟但带报价时间时，collector 按时间差派生（≤90 秒实时，否则延迟 N 秒）；四家适配器（东财/新浪/腾讯/Tushare）零改动自动生效，缺时间戳仍保守显示未知。

## 0.2.0（2026-10-31）

K 线图表与八市场支持。

### 新增

- **K 线图表**（lightweight-charts v5 vendor 内嵌，单文件装载）：分时（Area+均价线+昨收虚线，HH:mm 时间轴）、日K/周K/月K（蜡烛+MA5/10/20/60+成交量副图，红涨绿跌随显示偏好），周期按钮组+刷新+骨架/错误/空态，主题跟随宿主色板重涂。
- **八市场**：沪/深 A 股、港股（00700 五位补零）、美股 NYSE/NASDAQ（secid 动态归属）、日经、韩证、伦敦。市场元数据（币种/价差/时区）单源 MARKET_META 下发。
- **K 线数据管道**：东财 push2his 主源（klt 101/102/103、qfq）+腾讯 fqkline 备源（键名漂移兜底+qt[4] 昨收）；kline-cache 三档 TTL（trend 不落盘/日K 1h/周月K 24h），routingRevision 失效；executor 8s 滑动超时+failover。
- **多市场搜索**：候选带市场与币种徽标；remote 搜索市场面=启用实例适配器市场并集（suggest 全市场语义）。
- **一键为已启用市场配置K线**：设置页按钮走 check→configuration 合同（capability 并集全检）。
- 探针按市场代表证券直探（600519/000001/00700/AAPL/BABA/7203/005930/155.SHEL），八市场 verifiedByDefault=true。

### 修复

- 设置页 providers fieldset Array.map 缺右括号静默吞 children（M5.2）。
- 删除撤销横幅时序（M5.1）；watchlist securityId 八市场准入；kline GET query limit coerce；响应双层 data 包裹；路由上限 8→40；K 线额度/网络瞬时错误退避自动重试（按服务端 retryAfterMs）。
- 三角色评审收敛（2026-11-01）：宽屏详情返回入口常驻；一键 K 线成功/no-op 均有反馈且错误条可内联开启；搜索筛选补全八市场对称标签；移除"个股状态"死字段；别名 maxLength 对齐 30；高级预算项默认折叠；client 币种回退表删除（消除 GBP 漂移）。
