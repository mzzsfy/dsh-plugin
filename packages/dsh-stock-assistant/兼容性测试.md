## 2026-11-10 存量字段改名故障与存储布局迁移

0.5.0 把数据源凭据字段 `credentialEnv` 改名为 `credentialRef`，迁移写在 `openState`。宿主 `storageDomain.open` 先按新 schema 校验存量记录，`single` 布局又没有坏记录备份能力（single unit 无 `backupRecord`，`invalidRecords: 'backup-and-skip'` 不生效），于是数据域打开抛 `invalid-record`，插件 host 半区整体未激活：面板显示 `Unexpected token 'o', "not found" is not valid JSON`，数据区停在加载态。生产数据未丢（迁移前 revision 55 / 自选 12 / 路由 32）。

处置：归一挪到数据域 valueSchema（`storageDomain.open` 阶段），`openState` 不再改名；同时把存储改成控制面与缓存分域、按记录落盘，坏记录只丢自己。

验证（宿主 DSH 0.2.1-rc.2，storage-json 0.2.2-rc.1，真实 backend + 真实 `DomainFacility`，生产数据副本在系统临时目录）：

- 复现：修复前同一副本 `DomainError invalid-record`（表 control / 键 root）；修复后 `OPEN_OK`，providers 全为 `credentialRef`
- 完整 apply：真实 backend + `createApplication`，注册 12 条 API 路由与 vendor 前缀，零告警
- 布局迁移：旧 `stock_assistant.json` → `stock_assistant/control/root.json`，未声明的 cache 表不迁移，旧文件字节不变；迁移出的记录仍是旧字段，control 写入后才升级
- 坏记录隔离：per-record 下坏缓存被移成 `<键>.json.bak.<时间戳>` 后跳过，控制面与其余缓存照常打开
- 回归：包测试 339 项（含新增 S10/S11/S12、MIG06/MIG07、客户端 404 与中止用例）
- 口径变更：多笔成本由等权均价改为取最低价（列表/详情/概览/K线图例统一），每条成本仍各自显示百分比，标记页写明口径

未验证：迁移与迁移后行为都在临时目录副本上执行，未在生产数据目录重跑迁移；生产 3080 的恢复观察（HTTP 200、revision 62、12 只、32 路由）只覆盖 HTTP/JSON，未做面板视觉复测；真实非空密钥引用经真实数据域的路径（生产引用全为 null）。

## 维度检查点(补充)

1. **数据源矩阵**:八个市场各至少一次列表/详情/K 线;单一数据源失败时路由到备用源或给出可读错误,不整页空。
2. **交易时段**:休市快照冻结、当日/分时口径、时区与跨日;不得把休市当故障。
3. **预算与限流**:高频刷新触发限流时退避;多市场并发不超预算;页面切走/悬浮隐藏时降低采集。
4. **持久化代际**:`stock_assistant` v1 读写;旧域不存在时新建;域打开失败降级后操作按调用失败而非崩溃。
5. **token 边界**:无 Tushare token 时该源不可用且提示;token 不出现在日志/错误文本/前端可读位置。
6. **图表规模**:长 K 线/多指标开关不卡死主线程;缩放/拖拽/悬浮读数正确。
