## 已知边界

- POSIX 部署:本包全部行停用,功能面 1-11 不适用(预期:官方 bash 链照常)。
- headless(无 webServer):设置页路由跳过,settings.yaml 手工配置,能力不受影响。
- guard 代挂窗口内的官方工具为官方配置(官方 `shell` 节),本包设置页改动的 shell 清单不生效,属预期。
- 死态窗口(用户 patch 禁主行):agent preset 注入的官方 tool-pwsh 行因 `waiting for shell` 拒挂(cordis 服务按 fiber 树解析,guard 代挂对他树 preset scope 不可见),死态窗口新会话无 shell 工具属预期;guard 价值边界为救活 boot 组合与 host 面。正常窗口本包不改会话预设；经本包 `ctx.shell` 的官方非交互 pwsh 调用始终使用 PowerShell，不落默认客户端。
- 已存活代理与子代理可保留旧 `shell-select` 预设修订。显式指定已删除预设的部署须经宿主选择现存预设；本包不提供别名或迁移。
- 模型投影是展示策略而非权限限制：保留工具注册与 PowerShell 执行器，历史中知道 `pwsh` 名字的模型仍可能调用；已发送请求不追溯更改。投影按下一次组装生效，不依赖代理改选预设；卸载监听即复原。SDK renderer 不可用时告警并整体保留原展示，不发送半完成 SDK。
- pwsh 客户端 stderr 在非 UTF-8 console 代码页下中文可呈乱码(编码前缀只覆盖 stdout 面);执行与 exit code 不受影响。
- 受限模式 × Cygwin 系运行时(git-bash/msys2):confine 包装后 Cygwin mmap 在受限令牌下崩溃(`CreateFileMapping … fatal error`,exit 256)。失败可见、错误自解释,模型可换客户端或升权重跑;危险模式与 pwsh/cmd/wsl 不受影响。属 Cygwin 运行时限制,不做路径预判拦截。
- msys2 login 形:`-lc` 只把 /usr/bin 注入 PATH;/mingw64/bin 需 MSYSTEM=MINGW64 环境变量(条目 env 配置 `MSYSTEM: MINGW64`,或 OS 级全局环境继承——args 模板管 argv 不管 env)。未设时 gcc 类工具 command not found 属预期。
- wsl 形在未安装发行版的机器上:wsl.exe 输出 UTF-16 帮助文本呈乱码;正常发行版下 bash 输出走管道为 UTF-8 不受影响。

## 维度检查点(补充)

1. **接管序列**:禁用官方两行→官方退场→挂载执行器→核 `fiber.state`;任一步失败按回滚路径恢复官方链,不出现 shell 全灭窗口。
2. **写事务翻回**:POST 配置触发宿主重评 `!!js` 后,官方 `pwsh-sandbox` 翻回启用时先重发 disabled;成功保留执行器,拒绝或 30s 内连续 3 次才让位。
3. **投影与执行分离**:`shell` 可见时从实际 LLM 请求剔除 `pwsh` schema/段;`shell` 不可见时原样保留;历史/在途 `pwsh` 调用仍可执行;卸载监听即复原。
4. **平台矩阵**:pwsh、git-bash、cmd、WSL(指定 distro)、自定义路径各至少一条真实命令;POSIX 部署验证整包停用、官方 bash 链不变。
5. **sandbox**:read-only 写操作返回 `[sandbox: file access denied ...]` 与升权提示;升权后可执行;受限模式 × Cygwin 的 mmap 崩溃可解释、不误判为配置错误。
6. **deny**:绝对命中即拒且 spawn 未发生;前瞻豁免生效;坏正则不阻断保存;整文本正则不挡间接包装(已知边界)。
7. **错误可读**:坏路径、客户端不可用、WSL 无发行版均返回配置指引/可解释错误,而不是裸 ENOENT/乱码堆栈。

## 判据补充

上表 D01/D02/D04/D05/D06/D10/D11/D12 的检查点全部通过才可宣称 Windows 兼容;POSIX 只验证「整包停用+官方链不变」。维度补充检查点 1/2 属主功能回归,随每轮主测执行;5/6/7 至少每窗口各一轮。
