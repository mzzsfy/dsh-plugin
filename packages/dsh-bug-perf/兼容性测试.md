### L2 判据

- 仓库根 `node scripts/smoke-load.mjs`:本包有 `OK   @mzzsfy/dsh-bug-perf` 行,全仓 0 FAIL。
- 隔离环境 boot:bundles = 三基座 + `@mzzsfy/dsh-bug-perf`;boot 日志无本包行级 failed to import / did not activate;页面 console 出现 `[dsh-bug-perf] applied` 且无 `Failed to load plugins`。

0.2.1-rc.2 槽位实测(2026-11-07,`--only dsh-bug-perf --seed-gateway`):`activation live=true findings=0`、`browser ok=true consoleErrors=[]`、`importFailures=[]`、LLM 双协议往返 true;脚本判定 FAIL 的唯一原因是 `anthropicUpstream.userId` 为 `null`(judgeLlm 要求 `dsh:<40hex>` 的 gateway 标记断言,属 0.2.1-rc.2 宿主注释行为,与本包无关)。同工位功能探针:两功能 installed、20 次 `restart()`→3 次 attach、冻结 `revision` 26→27 自愈 + `terminal stalled` 日志 + `echo after-heal` 回显。据此 `dsh.hostMin` 定为 `0.2.1-rc.2`,`dshReleases."0.2.1-rc.2"` 记 `compatible`。

## 兼容性维度适用表

标记:M 手工必测 / A 自动化覆盖 / C 条件必测 / N 不适用。维度定义与判定口径见 [兼容性检查总纲](../../docs/兼容性测试/兼容性检查总纲.md)。

| 维度 | 标记 | 本包落点(检查点/证据) |
|---|---|---|
| D01 宿主代际与 API 契约 | M | 依赖宿主浏览器内部形态:`RemoteStream.prototype.restart`、`webTerminals` 视图、client 模块表、`/api/remote.mux` 路径与 `item` 帧协议(未知 streamId 被忽略)、`[data-chat-flow]` 容器与加载提示文案、全局 `WebSocket` 可包装;`hostMin=0.2.1-rc.2`,但 `socketKeepAlive`/`stuckSession` 目前只在 0.2.2-rc.1 验证;`installed: true` 只表示包装装上,不等于对既有连接生效;结构不匹配只记录原因或静默失效 |
| D02 运行平台与架构 | N | 纯浏览器半区补丁,无平台分支、文件、子进程与端口;host 半区只做配置分发 |

## 维度检查点(补充)

1. **官方形态复核**:宿主升级后逐项核对 `RemoteStream.restart`、`webTerminals.view`、client 模块表、`/api/remote.mux` 路径与 `item` 帧协议、`[data-chat-flow]`/`[data-chat-flow-key]` 结构、加载提示文案、全局 `WebSocket` 可包装性;模块/视图缺失时该补丁记 `waiting for ...` 或 `reason`,页面不报错;DOM/协议形态缺失时静默失效,须按 L3 #13-#23 复核。
2. **开关往返**:关闭 → 官方原名/未包装 → 重开 → 包装恢复;刷新页面后不残留包装,运行中禁用不撤销(已知行为)。
3. **合并边界**:窗口内 20 次 restart → 首次立即 + 一次尾随(约 2-3 次 open);窗口外逐次;不同 stream 不互相合并。
4. **看门狗边界**:未武装、页面隐藏、待渲染、无流、未连接均不触发;持续新帧不触发;冷却期不重复;新建视图自动武装。
5. **共存**:与 shared-terminal 同装时只读自愈走「接管输入」、看门狗走 `view.connect()`,两条路径不得同时抢同一终端。
6. **已知盲区**:本包是官方修复前的兜底,不是兼容性承诺;宿主已修复时应移除补丁而不是继续叠加。
