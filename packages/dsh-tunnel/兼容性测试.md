## 人工执行方式

1. `dsh plugin add @mzzsfy/dsh-tunnel` 装入 profile, 启动 `dsh web`
2. 路径模式: ai 调 `tunnel_open`(name/app, targetPort/本地 http 服务端口), 浏览器访问 `http://127.0.0.1:3080/p/app/`, 断言目标应用页面透出
3. 子域名模式: ai 调 `tunnel_open`(name/web, targetPort, entry/subdomain), 浏览器访问 `http://web.localhost:3080/`, 断言根部署应用页面透出且 WebSocket 应用(如 jupyter)内核通道可用
4. ai 调 `tunnel_list`/`tunnel_close`, 断言列表含 entry/access 与关闭后回落宿主页面
5. 重启 dsh, 断言两类隧道均自动恢复(重启前未 close 的条目)
6. 自动化: `node --test "test/*.test.mjs"` 全绿(行为语义) + `node scripts/compat/tunnel-fullchain.mjs` 全链路 PASS(真实实例七项探针)
